**AutoNews Show** is an interactive Unity broadcast that generates itself. It won the **AI Track at PantherHacks**.

## What I worked on

- Built an **LLM pipeline** that ingests **11 news RSS feeds** and uses Ollama to summarize them into broadcast-ready scripts.
- Used the **Google Cloud SDK** to batch-synthesize voice clips into an asset folder alongside script metadata.
- Created the interactive Unity show with **2–4 procedurally animated characters** delivering the segments.

## Highlights

- End-to-end automation: raw feeds in, a watchable broadcast out.
- Local summarization via Ollama, with cloud TTS for delivery.
- Procedural anchor animation so the cast feels alive without hand-keying.
