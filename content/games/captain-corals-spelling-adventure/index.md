**Captain Coral's Fintastic Spelling Adventure** is a cross-platform educational game for kids, built in Unity and C# with the Universal Render Pipeline.

## What I worked on

- Built a **web scraper** to analyze and verify the difficulty of over **300,000 words**, so the game could serve age-appropriate spelling challenges.
- Designed a scalable **ScriptableObject architecture** to manage data for **50+ fish objects**, keeping content authorable without touching code.
- Targeted the Universal Render Pipeline so the game runs across platforms with a consistent look.

## Highlights

- A data pipeline that turns raw word lists into graded, playable content.
- Designer-friendly content authoring via ScriptableObjects.
- Kid-first UX with readable, forgiving interactions.
